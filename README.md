# Sigma Inbox (FR-10) — Веб-версия: тесты и проверка контракта

Репозиторий с тестами для проверки соответствия **веб-версии** компонента `omninotice-notification-feed` контракту Apiary в рамках задачи **«Лента уведомлений (Inbox) в Sigma — веб и моб. версия (FR-10)»**.

> ⚠️ **Границы проверки:** проверена **только веб-версия**. Мобильная версия (React Native / WebView) и задача FR-11 («Всплывающее уведомление») в этом репозитории **не покрыты**.
